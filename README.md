# 생각펼치기 — 마인드맵 앱

컴퓨터와 휴대폰에서 쓰는 브레인스토밍·마인드맵 앱. 설치 프로그램 없이 브라우저에서 돌고, 홈 화면에 앱처럼 추가할 수 있다(PWA).

## 끝 기준
- 가지 글자를 누르면 바로 적을 수 있다. Enter·Tab으로 가지를 늘린다.
- 형식(6가지)과 테마(5가지)를 고르고, 시작 틀(10가지)로 새로 만든다.
- 새로고침해도 마인드맵이 남아 있다(기기 안 IndexedDB).
- 폭 390·768·1280에서 가로로 넘치지 않고, 브라우저 오류가 0건이다.

## 기능
| 기능 | 내용 |
|---|---|
| 형식 | 마인드맵(양쪽), 논리도(오른쪽), 조직도, 나무 목록, 타임라인, 버블 |
| 테마 | 산뜻한, 파스텔, 진한, 단정한, 밤하늘 |
| 시작 틀 | 빈 마인드맵, 버블 브레인스토밍, 공부 정리, 수업·학습 계획, SWOT 분석, 나를 소개해요, 사업·일 기획, 조직도, 한 주 계획, 할 일 목록 |
| 바로 적기 | 글자 누르기 → 적기, Enter 다 적음 → 다시 Enter 옆 가지, Tab 아래 가지, Shift+Enter 줄 바꿈, Esc 취소 |
| 옮기기 | 가지를 끌어 다른 가지 위에 놓기. 마인드맵에서 큰 가지를 반대쪽으로 끌면 옆이 바뀜 |
| 꾸미기 | 색, 모양(둥근 상자·네모·알약·동그라미·밑줄·글자만), 아이콘 24개, 메모, 그림 |
| 보기 | 지도 ↔ 목록(한 줄 = 가지 하나, Tab 안쪽·Shift+Tab 바깥쪽) |
| 집중 | 고른 가지와 그 위·아래만 밝게 |
| 발표 | 가지를 하나씩 펼치며 화면이 따라감(←·→, 누르기) |
| 내보내기 | PNG, PDF, 글 목록(.md), 백업 파일(.saenggak.json) |
| 기타 | 되돌리기·다시(Ctrl+Z·Y), 화살표로 가지 고르기, 두 손가락 확대, 휠 확대 |

## 실행법 (내 컴퓨터)
```
cd ~/work-kit/dev/saenggak
python3 -m http.server 8765 --bind 127.0.0.1
```
윈도우 브라우저에서 `http://localhost:8765` 를 연다.

## 휴대폰에 앱으로 깔기
공개 주소: https://jo6172-lang.github.io/saenggak/ (깃허브 페이지, 저장소 jo6172-lang/saenggak, 2026-11-26 올림. 기록 `~/work-kit/deploy/saenggak-2026-11-26.md`)
- 컴퓨터(엣지·크롬): 주소창 오른쪽 「앱 설치」 단추 또는 ⋮ → 「앱 설치」.
- 안드로이드 크롬: ⋮ → 「홈 화면에 추가」 → 「설치」. 아이폰 사파리: 공유 → 「홈 화면에 추가」.
- 기기 사이 공유: 첫 화면 「☁ 기기 사이 공유 켜기」 → 같은 구글 계정으로 로그인(파이어베이스 프로젝트 saenggak-48f47).
- 고친 뒤 다시 올리기: `git push` (공개라 사람 확인 필요). 되돌리기: `git revert` 후 push, 또는 저장소 비공개·삭제.

## 시험
```
python tests/desktop_test.py <결과폴더>   # 적기·형식·끌기·꾸미기·목록·발표·내보내기·다시 열기
python tests/mobile_test.py <결과폴더>    # 폭 390·768, 터치로 적기·꾸미기
```
(playwright가 깔린 파이썬으로 돌린다. 로컬 서버가 8765에서 떠 있어야 한다.)

## 파일
- `index.html` 화면 뼈대, `app.css` 모양, `app.js` 조작·저장, `layout.js` 자리 잡기·그리기, `templates.js` 시작 틀, `export.js` 내보내기
- `manifest.webmanifest`, `sw.js`, `icons/` 홈 화면 앱용
